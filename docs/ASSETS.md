# Asset provenance

- `hero.webp`: original AI-generated conceptual systems illustration, created for this portfolio. Decorative, not a screenshot of a real system.
- `projects/ecg-cover.webp`: original AI-generated conceptual ECG artwork; not experimental output or a clinical trace.
- `projects/cafe-cover.webp`, `projects/auction-cover.webp`: original AI-generated editorial project covers; not product screenshots or actual vehicle listings.
- `projects/focusflow-cover.svg`, `casting-cover.svg`, `vision-cover.svg`, `cloud-cover.svg`, `invoice-cover.svg`: original vector concept illustrations created for the project collections. These are decorative representations, not application screenshots or model output.
- `sri-lalitha-hero.webp`: existing portfolio asset retained from the source repository.
- `projects/cafe.webp`: public Billing-Software-for-Cafe repository, `docs/screenshots/billing.png`.
- `projects/auction.webp`: public bike-auction repository, `docs/screenshots/day8/detail-buyer-desktop-dark.png`; fictional demo listing.
- `projects/cleartrail.webp`: public cleartrail-evidence repository, `docs/preview.jpg`; synthetic demo workspace.
- `projects/indoharvest.webp`, `projects/tryfactor.webp`, `projects/clinic.webp`: read-only captures of publicly accessible site pages. Clinic capture contains only the public sign-in screen.
- Fonts: Bebas Neue and Manrope, from Google Fonts' source repository. SIL Open Font License files retained in `public/fonts`.

Raster images are locally stored as WebP; vector concepts use SVG. Cover art is distinguished from screenshots in project details. No Microlink or stock-image runtime dependency remains.
